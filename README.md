# IL course materials

Public course materials served via GitHub Pages at https://igorlogvinenko.com/IL-course-materials/

Structure: one folder per course (dwa103/, dwa227/, dwa490/), each with an index.html course hub,
a notes/ subfolder for lecture notes, and syllabi at the folder root. shared/ holds cross-course assets.
Root-level HTML files are redirect stubs kept so old links keep working. See ../WORKFLOW.md (local, untracked repo sibling) for publishing rules.
